# Demo Flow

This document will hold the final demo commands and expected talking points.

## Demo 1: bbtop

Show high CPU process detection and PID tree output.

## Demo 2: bbfscheck

Show disk usage, inode usage, and small file detection.

## Demo 3: bbnetmon

Show LISTEN, ESTABLISHED, and TCP state summary output.

## Demo 4: Benchmark

Compare equivalent sub-tasks rather than full feature sets.
